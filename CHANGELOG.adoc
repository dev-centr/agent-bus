== 2026-11-10

=== Names

Version 0.2.2 publishes the search phrases in `README.md`. The package name stays `agent-bus`. Harness interconnect and agent interconnect are among the phrases. Agent hub is not.

=== Registry readme

Version 0.2.1 publishes the root `README.md`. code.dlang.org reads that file. The AsciiDoc file stays beside it.

=== Agent bus

The package name is `agent-bus`. Version 0.2.0 is the first release under that name.

* `layer=mcp` is the harness's own MCP. It may route the action inside the harness.
* `layer=harness-commander` is every hop outside that MCP pattern: the CLI wrapper, the hack profile, and the warned state-database write.
* `agent-bus version` prints `0.2.0`.

=== D catalog command

Version 0.1.0 is the first registry release. The catalog command is a D program. `dub run --compiler=ldc2` replaces the Python package.

* `session-router version` prints `0.1.0`. `--version` stays the harness release being routed.

* Profiles, version inheritance, and the state-database refusal stay the same.
* Windows builds copy the SQLite library shipped with `d2sqlite3`.

=== Release-keyed doors

A release-keyed catalog chooses the first door that can perform a harness operation.

* Doors run in order: the harness MCP, a CLI wrapper, a hack profile, then a warned state-database write.
* A version with no profile, including commits between releases, uses the newest older profile.
* `session-router repair-needed` prints the fork and upstream pull request checklist.
* The state-database writer refuses the live Cursor database unless `--worst-case` and `--i-understand` are both set, and it does not rewrite the conversation blob.
